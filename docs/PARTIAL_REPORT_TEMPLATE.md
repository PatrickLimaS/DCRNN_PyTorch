# Partial Report Template

Use this template for every meaningful project checkpoint. One report per milestone or branch. Save under `docs/partial_reports/YYYY-MM-DD_<slug>.md`.

---

| Field | Fill in |
| --- | --- |
| **Date** | YYYY-MM-DD |
| **Report Type** | Partial progress / design note / ablation result |
| **Current Focus** | One-line phrase |
| **Status** | Pre-baseline / post-baseline / ablation in progress / paused / blocked |

## Checkpoint

Name of the specific milestone, branch, or decision point.

## Decision

What was decided and why, including alternatives rejected.

## Implementation Note

What was added, modified, or removed. Reference branches, PRs, file paths.

## Claim Boundary

- **What can now be said** (Tier 1 or, if upgraded, Tier 3 specification).
- **What must not yet be claimed** (Tier 4 future work).
- **What remains blocked**.

## Evidence

Run results, logs, metrics. Link to `empirical_validation/` when applicable.

## Next Action

Single next operational step.
