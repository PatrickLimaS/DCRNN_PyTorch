# Open empirical gaps

_Last updated: 2026-04-20_

## Gap 1: No scope-matched real benchmark

The current public claim rests on synthetic stand-ins only. No real benchmark with per-timestep cross-node shared structure has yet been completed.

## Gap 2: No out-of-scope probe has been run

Yearbook is framed as a scope / falsification probe but has not yet been executed in this validation layer.

## Gap 3: Residual gating has not earned its place

Residual gating remains a conditional extension and has not been validated as core.

## Gap 4: Adaptive scheduling has not earned its place

Adaptive scheduling remains a conditional extension and has not been validated as core.

## Gap 5: Real-benchmark seed stability is unknown

No real scope-matched benchmark has yet been run with a replicated multi-seed packet.

## Gap 6: Larger-graph behavior is untested here

The public claim is not yet backed by normalized evidence on larger real graph benchmarks in this validation system.
