# Robotic Vision Lineage

## Purpose

Position the system relative to robotic-vision research. No capability in any cited work is inherited.

## Correspondence

Robotic vision faces the same three asynchronous regimes as the cascade: multi-rate sensors (Stage A), heterogeneous compute across perception/estimation/planning (Stage B), anytime action commitment (Stage C). Architectural correspondence only — no robotics task is implemented or evaluated.

## Cited lineage

- **Event vision** (Gallego et al., 2022) — async pixel sensing, lineage for Stage A.
- **VLA models:** RT-2 (Brohan et al., 2023), OpenVLA (Kim et al., 2024), Octo (Octo Model Team, 2024) — pretrained vision encoders bridged into action/prediction heads.
- **Robot data at scale:** DROID (Khazatsky et al., 2024) — heterogeneous streams reference.

## Claim boundary

Not a robot policy. Not trained on or evaluated against robotics benchmarks. Citations are lineage, not evidence.
