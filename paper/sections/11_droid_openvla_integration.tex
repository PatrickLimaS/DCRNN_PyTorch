\section{DROID and OpenVLA as Integration Targets}
\label{sec:droid-openvla}

DROID~\citep{khazatsky2024droid} and OpenVLA~\citep{kim2024openvla} are
specified as integration targets; neither is used, trained on, or
benchmarked in this paper. DROID exercises Stage~A as a multi-rate
stream generator; OpenVLA can serve as an external oracle or a
drop-in Stage~C head on Stage~B output (optionally post-GRP). Interface
contracts are specified but not realized.
